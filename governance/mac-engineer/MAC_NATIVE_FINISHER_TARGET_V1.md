# ENGÜRÜ Mac Engineering™ — Mac-Native Finisher Target v1

## STATE

**TARGET DEFINED / MIGRATION NOT YET ACTIVATED**

## FINAL TARGET

ENGÜRÜ Mac Engineering™ is a Mac-native end-to-end engineering finisher.

It receives an engineering objective or product brief and can, within its authority:

`discover → inspect → research → plan → edit → build → test → repair → package → deploy → live-verify → rollback → Evidence → DoneCheck → finish`

The product runs on the Mac.

OSi Local Execution Runtime is the local execution substrate. It is not the product identity.

## REPOSITORY FABRIC TARGET

All governed `engurulabory/*` repositories required by the ENGÜRÜ system are present locally on the Mac under the established ENGÜRÜ workspace structure.

Each repository has:

- canonical local checkout;
- Git remote identity;
- exact local HEAD;
- observed remote main SHA;
- worktree state;
- role classification;
- local recovery mirror in GitVault;
- reconciliation state;
- Evidence history.

GitHub remains a synchronized remote publication / collaboration / recovery surface.

The Mac becomes the primary engineering execution surface only after migration acceptance is complete.

## NO SECOND TRUTH

During transition:

- GitHub current authority remains explicit;
- local engineering state is exact-SHA bound;
- local commits ahead of remote are marked pending reconciliation;
- GitVault mirrors remain recovery-only;
- authority promotion happens only through an explicit migration gate.

Offline work preserves continuity without manufacturing a second canonical truth.

## MIGRATION ACCEPTANCE GATES

The current GitHub-first authority may transition to Mac-native engineering authority only after:

1. governed repository inventory is complete;
2. every governed repository has a verified local checkout;
3. every local checkout has exact remote identity and SHA reconciliation;
4. GitVault recovery mirrors are complete;
5. offline commit queue is tested;
6. reconnect reconciliation is tested;
7. one multi-repository engineering task is completed locally end-to-end;
8. Mac restart/recovery preserves the task;
9. Evidence remains continuous;
10. DoneCheck v1.2 accepts the migration proof;
11. Human Threshold approves the authority transition.

Until then, the document is a target contract, not a claim that migration is complete.
