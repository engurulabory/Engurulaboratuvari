## INTENT

The user-facing product must make the current system understandable and operable without exposing engineering complexity as the default experience.

The primary desktop surface answers exactly three operational questions:

1. **Her şey yolunda mı?**
2. **Nerede dikkat gerekiyor?**
3. **Şimdi neye bakmalıyım?**

## CANONICAL UX DIRECTION

One canonical product direction is used.

The main desktop surface contains:

- ENGÜRÜ Mac Engineer™ identity;
- one clear overall state;
- attention surface only when attention is required;
- one clear next-action surface;
- the natural-language engineering composer as the primary interaction;
- concise access to deeper technical controls through secondary surfaces.

The main desktop surface does not depend on a persistent left sidebar.

Tasks, reports, settings, detailed technical history, diagnostics and repository controls remain available through secondary surfaces when needed rather than competing with the primary working view.

Recent-activity feeds, decorative counters and repeated explanatory copy are not required on the main surface.

## INFORMATION PRIORITY

Priority 1 — current state.

Priority 2 — attention requiring human awareness.

Priority 3 — next useful action.

Priority 4 — natural-language engineering interaction.

Priority 5 — advanced engineering controls on demand.

## AESTHETIC CONTRACT

The existing Aesthetic Motor™ capability is reused. No parallel aesthetic core is introduced.

The product direction must be:

- restrained;
- legible;
- desktop-first;
- product-specific rather than generic dashboard styling;
- visually coherent with ENGÜRÜ identity;
- original enough to remain distinguishable from generic AI chat/dashboard products;
- overflow-safe;
- responsive to practical Mac window resizing;
- keyboard-accessible for primary actions;
- readable under normal light/dark appearance constraints.

Visual decoration must support hierarchy and state comprehension.

## CURRENT-TO-TARGET DELTA

Measured current surface:

- sidebar: present;
- status drawer: present;
- new-work surface: present;
- chat composer: present.

Target contract:

- sidebar dependency: removed from the primary desktop surface;
- status: promoted into one compact primary state surface;
- attention: shown conditionally and explicitly;
- next action: visible without navigation;
- chat / natural-language composer: retained as primary interaction;
- advanced status, repository controls, diagnostics, settings and historical views: secondary/on-demand;
- existing runtime capability remains intact while the presentation layer is simplified.

## OVERFLOW + ORIGINALITY + ACCESSIBILITY GATES

Before Human Artistic Authority™ review, implementation must demonstrate:

- no horizontal overflow at supported desktop widths;
- no clipped primary controls;
- no modal/drawer collision with primary actions;
- no typography truncation that changes meaning;
- clear focus order for primary controls;
- distinct composition from generic sidebar + card-grid AI dashboards;
- one coherent canonical direction rather than several near-identical variants.
