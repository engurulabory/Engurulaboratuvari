### 5. Authorized macOS/Finder maintenance envelope

**READ_ONLY:** scoped inventory, Git truth, dependency/provenance inspection, security posture and health reporting, bounded diagnostics.

**SAFE_AUTO:** preauthorized reversible actions with exact target allowlist, precondition hash, sandbox/isolation, rollback and post-action verification. Automated deletion is not assumed safe by directory name.

**BOUNDED_WRITE:** isolated engineering changes with one writer, changed-path allowlist, snapshot/diff, regression tests and recovery receipt; protected sources preserved.

**HUMAN_REQUIRED:** deletion of personal/project/system data, irreversible deletion, critical Finder moves, history rewrite, repository archive/rename/merge/delete, system security changes, secrets/account authority, production releases or any other material external effect. Approval must refer to the exact paths, action, impact and recovery limits.

Finder scope requires consent to macOS privacy/TCC permissions, explicit user-selected paths, symlink/package/path traversal safeguards, protected-directory exclusions, dry-run preview, exact human confirmation for consequential operations and independent postcondition verification. No generic 'clean everything' wildcard authority.
